# 每日精读 · 微信小程序

学生端小程序。内容（文章、题目、音频）每天由 GitHub Action 上传到云开发存储，小程序直接读取，不需要改代码。

## 第一次使用

1. **导入项目**：微信开发者工具 → 导入项目 → 目录选这个 `miniprogram` 文件夹 → AppID 填你自己的小程序 AppID → 后端服务选"微信云开发"。
2. **填一行配置**：打开 `config.js`，把 `INDEX_FILE_ID` 引号里填上云存储里 `days/index.json` 的 File ID
   （云开发控制台 → 存储 → 打开 `days` 文件夹 → 点 `index.json` → 复制 "File ID"，形如
   `cloud://cloud1-xxxx.636c-cloud1-xxxx-1300000000/days/index.json`）。
3. **预览**：点"编译"看效果；点"预览"用手机扫码试用。
4. **给学生用**：点"上传"→ 公众平台"版本管理"里把这个版本设为体验版，再在"成员管理 → 体验成员"里添加学生微信号。
   想让学生直接搜到并且不限人数，需要提交审核、正式发布。

## 需要在公众平台设置的

- **用户隐私保护指引**（设置 → 基本设置 → 服务内容声明）：声明会使用"麦克风"（口语录音）和"剪贴板"（复制给老师），否则这两个功能会被拦截。
- 云存储权限保持默认"所有用户可读，仅创建者可写"即可。

## 功能

首页按日期选文章 · 单词卡（发音、音节、例句）· 阅读（重点词和重点句高亮、整篇朗读、阅读速度）·
6 道托福题（练习模式 / 计时测试模式，答后详细讲解：回到原文、逐项分析、解题三步；答对时选项分析折叠，答错时完整展开）·
思维导图填空 · 托福 Prose Summary · 口语录音（可发给老师）· 写作 · 成绩与薄弱题型 · 每日复习打卡（间隔重复）。

学习进度、打卡和录音保存在学生自己的手机上。
